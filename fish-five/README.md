# 물고기는 어디에 — 5번 해포리고기

HTML / CSS / JavaScript로 구성한 편집용 소스입니다. npm 설치나 빌드가 필요 없습니다.
마지막 물고기 영상은 제외했습니다. 기존 전시 서버 및 TouchDesigner 통신은 미연결입니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| index.html | 화면 구조, 버튼, 이미지 경로, 접근성 문구 |
| style.css | 위치, 크기, 색상, 등장 효과, 기포 움직임 |
| app.js | 순서, 횟수, 애니메이션, 화면 전환, 센서 |
| assets/ | 디자인 이미지와 수도꼭지·호스 애니메이션 프레임 |
| .nojekyll | GitHub Pages에서 정적 파일을 그대로 제공하기 위한 파일 |

## 먼저 실행하기

1. ZIP을 압축 해제합니다.
2. `fish-five` 폴더를 VS Code에서 엽니다.
3. PC에서 `index.html`을 브라우저로 열면 화면 흐름을 확인할 수 있습니다.
4. 수도꼭지를 세 번 클릭하고, 수평 안내에서 `PC 미리보기 · 수평으로 들기`를 누릅니다.

이 소스는 외부 폰트·라이브러리·JSON fetch에 의존하지 않습니다.
로컬 서버를 쓰고 싶다면 Python 설치 환경에서 이 폴더를 터미널로 열고
`python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`을 여세요.
아이폰 센서는 PC 로컬 미리보기와 별개로, HTTPS 배포 주소에서 확인하세요.

## 가장 자주 수정할 부분

`app.js` 맨 위의 `CONFIG`에서 수정합니다.

| 설정 | 기본값 | 의미 |
| --- | --- | --- |
| requiredTaps | 3 | 수도꼭지 터치 횟수 |
| rotationStepMs | 850 | 배경이 60도씩 회전하는 간격(ms) |
| fillPauseMs | 650 | 물방울 채운 뒤 대기(ms) |
| levelTolerance | 12 | 수평 오차 허용 각도. 크게 하면 쉬워짐 |
| levelHoldMs | 900 | 수평 유지 시간(ms) |
| videoSrc | 빈 문자열 | 추후 물고기 영상 파일 경로 |

`style.css`에서 `Ctrl+F`로 아래 선택자를 검색하세요.

| 검색어 | 수정 대상 |
| --- | --- |
| #stage | 전체 화면 비율 |
| .intro-one / .intro-two | 시작 말풍선 위치와 등장 시간 |
| .tap-card | 수도꼭지 영역 위치와 크기 |
| #tap / #hose | 수도꼭지와 호스 이미지의 위치 |
| .drop | 물방울 위치와 크기 |
| .fish / .fish-name | 물고기와 이름 위치·크기 |
| #rays | 방사형 배경의 크기·회전 효과 |
| .awake / .level | 등장 안내 / 수평 안내 위치 |
| .waiting | 마지막 말풍선 |

예: `.fish`의 `width: 56%`를 `60%`로 바꾸면 물고기가 커집니다.
`top`을 줄이면 위로, `left`를 줄이면 왼쪽으로 이동합니다.
화면은 원본의 390:844 비율을 유지합니다. 다른 비율의 기기에서는 여유 공간이 남을 수 있습니다.

## 글씨와 이미지 바꾸기

시작 버튼, 센서 버튼, 처음으로 버튼의 글씨는 `index.html`에서 바꿉니다.
센서 상태 안내 문구는 `app.js`에서 바꿉니다.

원본 손글씨를 유지하기 위해 디자인 속 말풍선·수도꼭지 안내 문구는 PNG로 넣었습니다.
이 문구는 `alt`를 바꿔도 화면 글씨가 바뀌지 않습니다. 일러스트레이터에서 수정해
해당 PNG를 투명 배경으로 내보내고 교체하세요. 물고기와 이름은 SVG입니다.

- intro1.png / intro2.png: 시작 말풍선
- instruction.png: 수도꼭지 안내
- awake.png: 물고기 등장 안내
- level.png: 수평 안내
- waiting.png: 마지막 기다림 말풍선
- fish.svg / name.svg: 물고기와 이름
- tap-0.png ~ tap-7.png: 수도꼭지 8프레임
- hose-0.png ~ hose-8.png: 호스 9프레임

기존과 같은 이름으로 교체하면 코드의 경로는 수정하지 않아도 됩니다.
프레임 개수를 바꾸면 `FRAME_TIMES` 배열도 개수에 맞게 수정하세요.

## GitHub Pages 배포

1. GitHub에서 저장소를 만듭니다. 무료 개인 계정이면 공개 저장소로 시작할 수 있습니다.
2. `fish-five` 폴더 안의 파일과 `assets` 폴더를 업로드하고 커밋합니다.
   **ZIP 자체를 올리는 것이 아닙니다. 저장소 최상위에 index.html이 있어야 합니다.**
3. 저장소의 `Settings → Pages`로 이동합니다.
4. `Build and deployment → Source`에서 `Deploy from a branch`를 선택합니다.
5. `Branch: main`, 폴더 `/(root)`를 선택하고 저장합니다.
6. 배포가 끝나면 Pages에 표시된 주소를 엽니다.
7. 수정 후 같은 파일을 다시 커밋하면 배포가 갱신됩니다.

출처: GitHub 공식 문서
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 아이폰에서 확인

HTTPS 배포 주소를 열고 수도꼭지를 세 번 누릅니다.
수평 안내가 나오면 `수평 감지 시작하기`를 누르고 권한을 허용하세요.
화면이 위를 보도록 휴대폰을 평평하게 들면 기다림 화면으로 넘어갑니다.
센서가 없거나 권한을 사용할 수 없을 때는 미리보기 버튼이 나타납니다.
PC에서 센서의 실제 동작을 검증할 수는 없습니다.

## 나중에 영상 추가하기

1. 영상을 `assets/fish-swim.mp4`로 넣습니다.
2. `CONFIG.videoSrc`를 `'assets/fish-swim.mp4'`로 바꿉니다.
3. 기다림 화면에서 수평이면 재생, 기울이면 일시정지하도록 연결되어 있습니다.

영상은 아직 연결·검수하지 않았습니다. 영상 크기와 말풍선 겹침은 추가 후 확인하세요.
영상 종료 후 자동 초기화는 현재 포함하지 않았습니다. 현재는 `처음으로` 버튼으로 돌아갑니다.

## 전시 서버와 연결

GitHub Pages에는 이 화면만 배포합니다. Node.js 소켓 서버는 기존 Render 등에 별도 실행합니다.
`app.js`의 `fish:waiting`은 같은 웹페이지 안에서만 발생하는 이벤트입니다.
이 이벤트를 실제 서버 메시지 전송과 연결하는 작업이 추가로 필요합니다.
기존 서버의 이벤트 이름·연결 주소를 확인한 다음 붙여야 합니다.
